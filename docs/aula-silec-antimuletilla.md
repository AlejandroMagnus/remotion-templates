# Aula SILEC — Regla Anti-Muletilla V2.1

La secuencia interna SILEC —hechos, prueba, norma, jurisprudencia, estrategia— gobierna el razonamiento, pero no debe convertirse en una frase repetida al comienzo de los videos.

Cuando el `hook` contiene tres o más componentes metodológicos presentados como cadena o fórmula de análisis, la capa audiovisual conserva intacta la ficha fuente y su revisión jurídica, registra el `hook` original para auditoría y abre públicamente con el problema humano concreto de esa ficha.

La forma de entrada varía por `productionCode`. Hechos, prueba, norma y estrategia permanecen dentro del desarrollo cuando aportan valor, pero dejan de funcionar como muletilla audiovisual.

Resultado buscado:

`problema concreto → consecuencia humana → descubrimiento jurídico → explicación → valor práctico`

La nomenclatura interna SILEC continúa fuera del discurso público salvo decisión editorial expresa.
